### 1.2 数据模糊化规则

| 原数据类型 | 脱敏处理 |
|-----------|---------|
| 客户年度GMV目标（10亿/13亿等） | "亿级目标" / "S级体量" |
| 客户年度广告费预算（1-1.5亿等） | "亿级广告预算" / "头部预算盘" |

| 客户负责人架构（负责人A管X/负责人B管Y） | 抽象为"客户对接人" |
| 平台资源比例（腾飞金20倍杠杆等） | "平台杠杆资源" / "节点扶持" |

### 1.3 平台政治雷区（必删）

以下内容在脱敏版中**全部删除或重写**：

1. ❌ 客户对微信豆"作弊产品"的负面定性 → ✅ 改为"客户对工具组合的信任度需要建设"
2. ❌ 羊毛党通过"送礼"功能漏洞攻击 → ✅ 改为"客户侧遭遇异常订单波动，已暂停相关链路"
3. ❌ 腾飞金20倍杠杆具体比例 → ✅ "平台节点扶持资源"
4. ❌ 客户内部汇报政治、对赌关系、IP博弈 → ✅ 全部删除
5. ❌ "腾讯广告" 字眼 → ✅ 全部替换为"腾讯营销"

### 1.4 内部作战细节处理（按 Q2 答案：保留方法论 + 抽象金句）

| 原内容类型 | 处理方式 |
|-----------|---------|
| 给客户的具体话术原文 | 删除原话，保留"沟通策略框架" |
| 必问问题清单（带客户对接人指向） | 改写为"销售下场前的5个 checkpoint" |
| 谈判筹码（带具体数字） | 抽象为"销售可输出的4类价值锚点" |
| 内部数据（A代/W/A自三主体ROI对比） | 改为"主体A/B/C，ROI 区间用'高/中/低'描述" |
| 沟通风险预判 | 保留方法论，删除涉及客户具体说法的内容 |

### 1.5 抽象金句保留示例（让听众感受到"销售真的下场了"）

可以保留的"金句感"表达（不涉敏）：

- ✅ "客户在 Q1 已经验证了链路跑得通，Q2 的关键不是'能不能做'而是'怎么做大做稳'"
- ✅ "当客户的后台 ROI 和财务实际有偏差时，销售的工作不是再推数字，而是先帮客户建立归因信任"
- ✅ "母婴营养品的复购被收割，本质不是价格输了，是信任输了"
- ✅ "高客单+高信任=高复购飞轮，低客单+低信任=被收割宿命"

## 三、引用规范

### 3.1 引用脱敏版的标准表述

> "下面这个案例，我用了客户化名 N。这是我们团队服务的一个 S 级膳食头部客户……"

### 3.2 不要做的事

- ❌ 不要在 townhall 现场口头补全"客户N就是诺特兰德"（即使私下问也不接）
- ❌ 不要把脱敏版数据和原版数据混用在同一份PPT
- ❌ 不要在脱敏版基础上"反向加料"还原真数据

### 3.3 出现意外被问到时

> 标准应答："具体客户名涉及合作保密，今天分享的核心是方法论。这套打法在头部客户身上跑通了，后面有兴趣的同事可以私下交流落地细节。"
