# 客户Q1复盘沟通 · 情报解读方法论

> 案例背景：S级头部客户N · Q1业绩复盘与下半年大促策略沟通
> 视角：销售如何在一次会议里完成"情报刷新 + 认知修正 + 下季度作战重排"
> 适用场景：townhall 分享 / 团队带教 / 销售作战流程标准化

---

## 一、为什么这次沟通值得复盘

会议是常规季度复盘，但销售从中拿到了**3个会前完全没有的情报**，并对**3条原有作战路径做了修正**。
这是一个典型的"销售情报采集"案例。

---

## 二、情报分类法：销售要把信息分成三档

### 2.1 🔴 重大新情报（会前不掌握的）

| 类型 | 情报 | 销售应该做什么 |
|------|------|--------------|
| 业绩 | 客户已完成 Q1 目标进度 | 重新校准下季度的作战节奏 |
| 数据真相 | 后台ROI 偏高，但客户财务侧实际承压（归因重合） | 销售工作的重心从"推数字"转为"帮客户建立归因信任" |
| 链路变化 | 某条核心链路因运营异常临时关停 | 短期内对该链路的"放量建议"必须修正 |
| 品类风险 | 某主推品类出现退款率显著高于行业均值的情况 | 暂停"扩量"推荐，转向"风控+客单价调整" |
| 渠道结构 | 达人渠道贡献的 GMV 占比远高于自营预估 | 投放资源优先级重排，向达人侧倾斜 |
| 工具偏好 | 客户对某个投放工具的信任度需要建设 | 销售换话术，从"工具优势"转为"工具组合稳定性" |
| 客户主动信号 | 客户计划做"店铺隔离"解决归因问题 | 配合做投放账户结构调整 |
| 大促资源 | 节点扶持资源已锁定 | 立即帮客户走申请流程 |

### 2.2 ✅ 验证了会前预判（销售作战节奏不变）

| 预判 | 验证 |
|------|------|
| "小店是核心亮点" | ✅ 完全验证 |
| "品类集中度过高" | ✅ 完全验证 |
| "下季度某节点是关键窗口" | ✅ 完全验证 |

### 2.3 ❌ 必须修正的会前预判（销售作战节奏要变）

| 原预判 | 修正方向 | 修正逻辑 |
|--------|---------|---------|
| "某品类 ROI 高，建议扩量" | **暂停扩量** | 退款率显著偏高，ROI 是虚高的，先解决风控 |
| "某链路放量是补课方向" | **改为重建** | 该链路已临时关停，需要先恢复再讨论放量 |
| "推荐用工具A作为主力" | **改为以工具B为主，工具A仅做补充** | 客户对工具A的信任度需要更长时间建设 |

## 三、销售作战的"3个认知修正"模板

> 销售在每次重要客户会议后，都应该问自己：今天会议结束，我对这个客户的认知刷新了哪3条？

### 修正1：渠道结构

**原认知**：自营直播+小店双引擎 →
**新认知**：达人矩阵+小店直购+节点扶持杠杆

> 内核：**销售对客户的渠道画像，必须随客户实际经营动作动态更新，不能停留在"上次见面时"的版本。**

### 修正2：工具组合

**原认知**：推荐 ROI 高的工具作主力 →
**新认知**：以"客户信任度高+长期稳定"的工具为主，ROI 高但客户存疑的工具仅做样本补充

> 内核：**销售推工具，要看客户的"心理账户"，不只看后台数字。**

### 修正3：品类策略

**原认知**：高 ROI 品类应该扩量 →
**新认知**：先看真实退款率，ROI 减去退款率才是销售应该看的"健康度"

> 内核：**销售要建立"健康ROI"的二次校准习惯——后台 ROI ≠ 客户财务侧的真实ROI。**

## 四、销售作战的"4个核心抓手"刷新（基于会议情报）

| 抓手 | 内容 | 优先级 |
|------|------|--------|
| 1 | **节点扶持资源申请** | 🔴 P0 本周完成，资源是大促胜负手 |
| 2 | **风险品类暂停 + 风控方案** | 🔴 P0 立即调整，避免越投越亏 |
| 3 | **新窗口期品类的工具测试** | 🔴 P0 本周启动，跑数据 |
| 4 | **大促达人矩阵的素材+预算配合** | 🟡 P1 月底前完成 |

## 五、销售在客户面前的"微妙信号"识别能力

> 这是销售要锻炼的隐性能力——客户讲的每句话都不只是"陈述"，可能藏着"立场"。

| 信号类型 | 识别方法 | 应对 |
|---------|---------|------|
| 客户主动提"另一个头部品牌的经验" | 客户知道你同时服务多家头部，态度是"学习"还是"攀比" | 健康关系=继续服务；攀比信号=要做信息隔离 |
| 客户对某工具用负面词 | 信任度问题 | 不再用该工具的"亮点数据"做推销 |
| 客户主动谈"风控/异常" | 客户已经在认真处理问题 | 销售配合，不再追问数据 |
| 客户主动谈"资源/补贴" | 大促预算节奏即将启动 | 立即跟进资源对接 |

## 六、销售下次见面前的"准备清单"模板

每次会议结束，销售要立刻列出"下次见面前必须准备好的物料清单"：

| 类别 | 物料 |
|------|------|
| 资源类 | 节点扶持资源申请结果（名额是否锁定） |
| 数据类 | 新品类工具测试初步数据（至少跑1周） |
| 方案类 | 风险品类的客单价/SKU 重组方案 |
| 节奏类 | 大促期完整商家排期表 + 平台资源日历 |
| 工具类 | 客户要求的工具权限确认 + 初版分析报告 |
| 内容类 | 大促达人矩阵的投放策略文档 |

---

## 七、一句话总结（金句版）

> **一次好的客户会议，对销售来说不是"沟通完了就交差"，而是"情报刷新+认知修正+作战重排"的三件套。**
> **销售要练的是：会议结束的那一刻，立刻能在脑子里画出"作战地图的差异版"——哪几条线变了、哪几条线没变、哪几条线必须立刻动。**
