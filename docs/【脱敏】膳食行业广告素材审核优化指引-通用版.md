## 一、近期高频卡审类型总览

根据近期膳食行业商家素材审核数据，以下六类违规是导致人工复审通过率低的主要原因，按发生频率从高到低排列：

| 序号 | 违规类型 | 高频程度 |
|------|---------|---------|
| 1 | 前后对比暗示功效 | 🔴 极高 |
| 2 | 叙事引导功效关联（症状→产品→改善） | 🔴 极高 |
| 3 | 油脂/内脏画面暗示 | 🟡 高 |
| 4 | 绝对化/夸大用语 | 🟡 高 |
| 5 | 产品名称/包装误导 | 🟡 中（新增） |
| 6 | 无来源数据宣称 | 🟢 中 |

> ⚠️ 特别提示：2026 年 3 月 13 日起，微信小店发布专项治理公告，对虚假宣传商品功效行为的处罚已升级——一般违规即封禁橱窗功能 + 暂停直播能力，严重/多次违规将永久封禁。详见第二章。

## 二、【新增】微信小店虚假宣传专项治理要点

### 2.1 治理背景

2026 年 3 月 13 日，微信小店交易规则中心发布《关于带货者虚假宣传商品功效行为的专项治理公告》，对直播带货场景中的虚假宣传行为进行专项整治。膳食行业所涉及的保健食品、传统滋补食品、山货食品均为本次治理重点品类。

### 2.2 三类核心违规行为

| 违规类型 | 行为描述 |
|---------|---------|
| 直接功效宣称 | 普通食品宣称疗效、保健食品宣称代替药物 |
| 暗语/隐喻间接宣称 | 用「关键时刻」「扛事」「乾坤丹」等替代直接功效词 |
| 虚假名称包装 | 普通食品包装为「藏雪莲参」等具有功效暗示的名称 |

### 2.3 处罚力度（已升级）

| 违规程度 | 处罚 |
|---------|------|
| 一般违规 | 封禁橱窗功能 + 暂停直播能力 |
| 严重/多次违规 | 永久封禁带货资格 |
| 涉及虚假名称 | 商品下架 + 店铺扣分 |

### 2.4 膳食行业合规红线

- **保健食品**：不得用绝对化词语描述功效；不得宣传代替药品或具有治疗效果
- **普通食品/山货/滋补**：不得通过明示或暗示方式虚构医疗、保健功效；不得使用"暗语""隐喻"替代直接功效宣称
- **所有品类**：不得使用虚假前后使用效果对比来夸大商品功效
- **产品包装/名称**：不得用虚假名称包装普通食品以误导消费者认知

## 三、逐项违规解析与修改建议

### 3.1 前后对比暗示功效

**违规表现**：
- 画面出现身体部位使用前后的直接对比（如眼睛充血→清澈、皮肤粗糙→光滑）
- 视频封面使用对比图暗示产品效果
- 体重/身材/体型的使用前后对比
- 直播封面为不实对比图（本次专项治理明确列出）

**判定逻辑**：只要画面中出现同一主体的「状态 A→状态 B」变化，且与产品使用存在关联暗示，即判定为功效宣称违规。**不论是否有文字说明**。

**修改建议**：
- 改用「成分展示」「工艺展示」「场景使用」类画面
- 多人不同场景使用素材替代单人前后对比

### 3.2 叙事引导功效关联

**违规表现**：
- 视频按「症状描述→引出产品→症状消失」的结构编排
- 口播按「你是不是经常 XX（症状）？试试这个」的话术引导
- 使用「关键时刻」「扛事」等暗语间接暗示治疗效果
- 山货/滋补品用「乾坤丹」「延年益寿」等夸张叙事

**判定逻辑**：视频/口播的叙事结构如果构成「问题（症状）→方案（产品）→结果（改善）」的因果链，即被判定为功效引导。**即便不直接说"治""疗效"，暗语和隐喻同样违规**。

**修改建议**：
- 叙事终点停在「补上了缺口」「满足了需求」，不能滑向「变好了/解决了」
- 用场景描述替代症状描述（「忙碌一天后」可用，「经常失眠的朋友」不可用）

### 3.3 油脂/内脏画面暗示

**违规表现**：
- 画面展示油脂溶解、肠道清理等动态效果
- 通过动画/实拍展示「体内毒素排出」等过程
- 展示血管疏通等医疗相关视觉效果

**修改建议**：成分动画聚焦在「成分本身」（分子结构、来源），不涉及人体内部作用过程。

### 3.4 绝对化/夸大用语（本次专项重点强化）

**违规表现**：
- 「最」「第一」「唯一」等绝对化用语
- 「秒入睡」「无副作用」等夸大治疗承诺
- 保健食品宣称「可以代替药品」
- 普通食品宣称「预防感冒」等医疗功效

**修改建议**：
- 「最低价」→「非常有诚意的价格」
- 「效果最好」→「品质优选」
- 保健食品类话术统一加「本品不能代替药物」标注

### 3.5 产品名称/包装误导（本次专项新增）

- 产品名称必须如实反映产品真实属性和主要成分
- 不得使用夸张、误导性的命名方式
- 包装设计应与产品实际成分和功能相匹配
- 如需使用传统概念，须有真实工艺/配方依据

### 3.6 无来源数据宣称

- 所有数据宣称必须标注第三方证明来源
- 「90% 的中国孩子……」需有公开权威数据支撑
- 「研究表明……」必须附具体研究出处

## 五、素材提审前合规自查清单

每条素材在提审前，须逐项核对以下清单。**全部通过后方可提交**：

### A. 画面维度

- [ ] 无任何形式的前后对比画面（身体/皮肤/眼睛/身材/体重）
- [ ] 无油脂溶解、肠道清理、血管疏通等功效暗示画面
- [ ] 无胖瘦身材对比
- [ ] 直播封面不使用对比图
- [ ] 无未授权的明星/IP/品牌素材
- [ ] 无二维码引导站外

### B. 文案/口播维度

- [ ] 无绝对化用语（「最」「第一」「唯一」「秒入睡」「无副作用」等）
- [ ] 无疾病治疗/预防宣称（普通食品不得关联任何疾病）
- [ ] 无「代替药品」等表述（保健食品须标注「本品不能代替药物」）
- [ ] 无暗语/隐喻暗示功效（如「关键时刻」「扛事」「乾坤丹」等）
- [ ] 保健食品仅宣传批准范围内的保健功能
- [ ] 数据宣称均有第三方证明来源
- [ ] 无焦虑营销话术（「不吃 XX 你身体就完了」）

### C. 叙事结构维度

- [ ] 视频不存在「症状→产品→改善」的因果链叙事
- [ ] 口播不以身体不适/疾病症状作为引入
- [ ] 产品介绍聚焦成分/工艺/原料，而非效果/疗效
- [ ] 使用感受类表述加注「个人体验，效果因人而异」

### D. 产品信息维度（本次新增）

- [ ] 产品名称如实反映真实属性，无虚假命名
- [ ] 直播展示商品与实际发货完全一致
- [ ] 口播信息与商品详情页保持一致
- [ ] 食品类清晰展示生产日期和保质期

## 六、核心合规原则

膳食行业素材创作的四大安全原则：

### ▎ 只说「是什么」，不说「能做什么」

描述产品成分、原料、工艺，不描述产品功效、疗效、改善结果。

### ▎ 只说「感受」，不说「效果」

「口感顺滑」「质地清爽」可以说，「吃完感觉精神了」不能说。

### ▎ 只说「场景」，不说「症状」

「忙碌一天后来一杯」可以说，「经常失眠的朋友试试」不能说。

### ▎ 只说「成分科普」，不说「功效科普」

「含 XX 营养成分」可以说，「XX 成分能治 XX」不能说。

### 补充原则（基于本次专项治理）

- **不用暗语代替直接表述** — 「关键时刻」「扛事」等暗语与直接说「治病」同样违规
- **不用虚假名称包装产品** — 产品名称必须如实反映真实属性
- **保健食品必须标注「本品不能代替药物」** — 任何暗示代替药品的表述都是违规
- **普通食品零功效宣称** — 无论明示还是暗示，普通食品不得关联任何医疗/保健功效

### ⚠️ 关于「广告侧 vs 直播侧」标准不通用的提醒

直播治理侧和电商（广告审核）侧是**独立体系**，各自的放宽标准**不通用**。本指引第四章的话术对照表为**广告侧标准**，在直播间使用这些话术，需要**单独验证直播治理侧是否认可**。
