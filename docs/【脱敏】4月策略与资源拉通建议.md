## 一、为什么需要"资源拉通"这件事？

**销售一个人能做的事是有限的。**

膳食行业的客户卡点，多数不在"投放策略"本身，而在：

- 平台能力（小店、视频号、搜一搜品专）
- 产品政策（互选、加热、全域通）
- 审核尺度（品类合规、素材边界）
- 品牌资源（溯源、IP、节点)

这些**销售一个人推不动**，必须借电商大库的友军 —— 平台 / 小店 / 市场部 / 审核 / 运营 / 产品部门。

军师的工作：把"客户面 + 友军面 + 一句话提案"打包好，**让跨部门同事一看就知道为什么要帮**。

## 六、军师如何"打包好"再交给销售？

军师生成的"跨部门提报"标准结构：

```
【一句话提案】
为什么这件事重要 + 需要谁支持 + 期望什么结果

【客户面】
- 客户当前状态 / 痛点
- 客户已经做了什么
- 客户期望什么

【友军面】
- 这件事对友军部门的价值（不是单方面索取）
- 友军可能的顾虑 + 提前应对
- 双方共同的产出物

【行动清单】
- 我（销售）会做什么
- 友军部门需要做什么
- 时间表 + 责任人
```

> 💡 **核心理念**：跨部门协作不是"求人帮忙"，而是"让对方看到自己的价值"。军师替我把"为什么要帮"写清楚，对方一看就知道这事对他也有好处。
