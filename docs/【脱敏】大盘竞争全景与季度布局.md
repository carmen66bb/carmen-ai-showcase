# PART 1：大盘竞争全景分析

## 一、大盘核心数据一览

| 指标 | 最新数据 | 环比变化 | 态势判断 |
|------|----------|----------|----------|
| 大盘日均消耗 | 季度峰值 | +11-14% | 🟢 大盘持续放量 |
| 活跃客户数 | 大盘客户数 | +8.2%（+18 家） | 🟢 客户基础扩大 |
| 有消耗账户数 | 大盘账户数 | +26.4%（+113 个） | 🟢 基建加速 |
| 大盘平均 ROI | 1.77-1.79 | -3.8% ~ +1.3% | 🟡 效率微降但可控 |
| 竞价 CPM（全渠道） | 70-84 元 | +8% ~ +38.5% | 🔴 流量成本上涨 |
| 竞价 CPM（纯直播） | 146 元 | +124.8% | 🔴 直播赛道 CPM 暴涨 |
| 大盘 CTR | 2.29-2.37% | +20.5% ~ +24.1% | 🟢 素材效率回升 |
| 浅层 CVR | 3.27% | -8.2% | 🟡 转化率微降 |
| 智投渗透率 | 18.5-22.1% | ↓ | 头部客户手动操盘 |

**核心判断**：

1. **大盘处于"景气但拥挤"的状态** —— 日耗持续放量，但 CPM 暴涨说明竞争加剧
2. **CTR 修复是季度最大亮点** —— 从低点回升 +20%，素材危机已解除
3. **CPM 通胀是下季度最大威胁** —— 纯直播 CPM 暴涨 +125%，eCPM 不达标的品牌加速被淘汰

### 2.2 三大结构性趋势

**趋势一：CPM 通胀时代来临**
- 全渠道 CPM +38.5%，纯直播 CPM +125%
- TOP1 高消耗低效率推高全行业 CPM
- **影响**：eCPM 竞争淘汰赛开启，效率差的品牌会被系统减量

**趋势二：直播 - 小店双引擎成为标配**
- 客户 N 小店占比已达 61%，验证了小店规模化路径
- 纯直播品牌（TOP1、B1、X）抗风险能力偏弱
- **影响**：下季度推动更多客户开通小店是重点工作

**趋势三：高客单直播崛起**
- 客户 H（高客单）、X（高客单）、高风险客户矩阵（中客单）验证了高客单 × 直播的可行性
- 高客单 eCPM 天花板更高，在 CPM 通胀环境中有天然优势
- **影响**：高客单品类将成为大盘增量的重要来源

## 三、我方客户逐个诊断

### 3.1 TOP1（S 级 | TOP1 | ⚠️ 效率危机）

| 关键指标 | 数据 | 判断 |
|---------|------|------|
| 日耗 | +56.7% | 🟢 规模大幅增长 |
| ROI | 1.33（-5.0%） | 🔴 距红线仅 0.03 |
| 渠道结构 | 直播 100%，小店 0% | 🔴 极度单一 |
| 主播矩阵 | 主播 A 新晋第一，主播 B 暴跌 -86.5% | ⚠️ 剧烈重组 |
| 占大盘比例 | 29.4% | ⚠️ 系统性风险来源 |

**核心风险**：占大盘 29.4%，如果 ROI 跌破阈值触发限量，大盘将承受系统性冲击。

**下季度关键动作**：

1. ROI 止跌是第一优先级
2. 推动开通小店渠道（已建议多次但未落地）
3. 监控主播 A 稳定性（新间需验证持续性）

---

### 3.2 客户 H（S 级 | TOP2 | 🟢 最均衡的增长）

| 关键指标 | 数据 | 判断 |
|---------|------|------|
| 日耗 | +22.8%~+56.3% | 🟢 稳健增长 |
| ROI | 1.98-2.01 | 🟢 效率健康 |
| 新增长曲线 | +147%~+202% | ⚡ 第二增长曲线爆发 |
| 小店 | 停滞 | 🔴 最大短板 |
| 广告依赖度 | 83.7% | 🔴 过度依赖付费 |

**核心发现**：新增长曲线（纤体管理方向）从萌芽变为支柱。但小店停滞是最大短板。

**下季度关键动作**：

1. 新增长曲线全力加速（开智投 + 扩素材）
2. 小店破局（扩品 + 提智投 + 素材换新）
3. 直播间矩阵从 3 间→6 间降低单点风险

### 3.3 客户 N（S 级 | TOP3 | 🟢 效率之王但增速放缓）

| 关键指标 | 数据 | 判断 |
|---------|------|------|
| 三主体合计 | -10.2%~持平 | 🟡 整体微缩量 |
| 主体 A 小店 | +34.4% | 🟢 核心引擎爆发 |
| 主体 A 小店占比 | 60.7%（vs 上期 44.5%） | ⚡ 渠道结构质变 |
| 主体 B 自营 | -54.1% | 🔴 持续恶化 |
| 主体 C 代理 | -51.1% | 🔴 代理疑似撤资源 |

**核心发现**：主体 A 小店渠道占比跃至 60.7%，模式验证成功。但主体 B 和主体 C 同时大幅缩量，三主体合计被客户 H 反超。

**下季度关键动作**：

1. 主体 B 自营止跌（ROI 效率极好，缩量是浪费）
2. 主体 A 小店继续扩品
3. 主体 C 战略评估（确认代理意愿）
4. 品牌营销升级（大体量客户仅停留在达人种草 = 严重低配）

## 七、下季度战略方向

### 7.1 架构调整对销售的影响

根据组织架构调整：

- **品牌与竞价分离**：直属总监负责竞价型，盘子变小但聚焦
- **核心指标变化**：品牌业务从招商 / 合约 → 互选 / 加热指标，核心是用户信任和资产
- **产品矩阵**：全面拥抱微信豆、AdQ、全易通

### 7.2 下季度四大战略方向

**方向一：小店规模化（最大增量来源）**
- 目标：小店日耗翻倍
- 路径：客户 N 扩品 + 客户 H 小店破局 + 新客户开通小店
- 关键指标：小店客户数从 5 家→10 家+

**方向二：效率优化（ROI 防线）**
- 目标：大盘 ROI 维持 ≥1.75
- 路径：TOP1 ROI 止跌 + 客户 J 冷启动效率提升 + 全行业 CTR 优化
- 关键动作：建立"ROI 红线预警机制"（自动监控 + 分级响应）

**方向三：高客单直播深耕**
- 目标：客户 H + 客户 X 直播日耗稳定在双数位级
- 路径：客户 H 新增长曲线加速 + 客户 X CID 规模化 + 素材方法论跨客户复用
- 关键动作：客户 H CTR 2.12% 的素材方法论 → 复用到客户 X（CTR 仅 1.71%）

**方向四：新客户孵化**
- 目标：培育 2-3 个新的 A 级客户
- 路径：微信豆转 ADQ SOP 推广 + 小店首开扶持

## 九、一句话总结

> **军师在季度收官前 10 天**，把所有客户的"两稳两危一新"格局梳理清楚，让我知道**资源该压哪、风险该防哪、未来该建哪**。中长期最大的战略杠杆是"小店规模化" —— 当前小店 73.5% 集中在一家客户，推动其他头部客户开通小店是下季度日耗冲量的关键路径。这就是"持续让行业胜出"。
