# 视频号《医疗健康行业公约》× 膳食类目 机会风险分析

> **政策来源**：视频号直播医疗健康行业公约（2026 年 4 月 13 日生效）
> **分析时间**：2026 年 4 月 21 日
> **分析目的**：判断新公约对膳食行业不同类目的影响，识别机会与风险
> 本文件已做客户名脱敏处理（客户名以代号显示）

## 一、新公约核心变化速览（与膳食行业有关的部分）

| 条款 | 内容要点 | 对膳食行业的影响 |
|------|---------|----------------|
| **医疗科普直播禁带货** | 定义为「医疗健康科普」的直播，主播不得使用商品信息分享功能（不能挂车） | 🔴 直接打击「科普+带货」模式 |
| **普通商品禁宣疗效** | 严禁宣称食品、保健品、药材等普通商品具有「预防疾病、治疗功效」 | 🔴 膳食行业最高频违规点被重申 |
| **跨类目医疗宣传禁止** | 在非医疗直播（如电商带货）中出现医疗、养生类内容属违规 | 🟡 科普型带货内容需重新审视 |
| **伪装医生禁止** | 穿白大褂、使用实验室场景暗示医疗身份 | 🟡 部分品牌「科研场景」直播间需排查 |
| **虚假人设禁止** | 虚构身份、编排情节诱导消费 | 🟡 达人/IP 人设合规需加强 |
| **夸大宣传红线** | 宣传产品具有减肥、壮阳、增高、根治等功效 | 🔴 与膳食高频品类直接冲突 |
| **伪养生禁止** | 缺乏科学依据且损害健康的养生功法 | 🟡 部分养生茶/食疗类内容需排查 |
| **生长发育需资质** | 无「健康科普」资质账号不得涉及儿童青少年生长发育内容 | 🔴 直接影响儿童营养品类 |
| **减肥/控糖需资质** | 宣传特定运动或饮食具有快速减肥、控糖功效需资质 | 🔴 直接影响体重管理品类 |

## 二、膳食各类目机会风险矩阵

### 🟢 机会区（政策利好 or 影响可控）

#### 1. 维矿物质 / 钙铁锌 / 蛋白粉 — ⭐ 最安全类目

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 N（主力品类）、客户 H（部分） |
| **新公约影响** | 🟢 几乎无影响 |
| **理由** | 属于「普通膳食营养补充食品」，不涉及医疗科普定义；话术以「补充 XX 营养」为主，天然远离功效宣称红线 |
| **机会** | 新公约收紧其他品类后，维矿物质/钙铁锌类是**最安全的投放标的**，可承接从高风险品类转移过来的预算和流量 |
| **建议** | 保持现有话术，可作为「合规标杆」品类向治理侧展示 |

#### 2. 胶原蛋白 / 虾青素（美容营养方向）— ⭐ 有空间但需话术纪律

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 W（虾青素、胶原蛋白） |
| **新公约影响** | 🟡 中等风险，话术边界需收紧 |
| **理由** | 「抗氧化」功效已有放宽话术（「对抗自由基」「皮肤暗沉」可用），但新公约重申「夸大宣传」红线，「变白」「紧致」「逆龄」等仍是禁区 |
| **机会** | 已有明确的「可用话术白名单」，只要严格执行白名单，合规空间反而比竞品更大——竞品如果乱说会被打掉，合规品牌反而受益 |
| **风险** | 「祛黄褐斑」方向的放宽话术非常窄（只能说「呵护肌肤」「减少色素沉淀」），主播极易越界 |
| **建议** | 客户 W 多间直播间需统一话术卡片，将「可用/不可用」对照表做成主播桌面贴纸 |

#### 3. 鱼油 / 磷虾油（血脂健康方向）— ⭐ 有明确放宽通道

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 N（部分品类） |
| **新公约影响** | 🟡 需注意不能提「血管养护」 |
| **理由** | 内部规则已放宽「鱼油可呵护血脂健康、减少血管壁油脂」，但明确标注**不支持「养护血管类」描述**。新公约将此类描述归入「夸大宣传」 |
| **机会** | 鱼油是中老年高需求品类，养老金上涨 + 社区养老政策利好需求端。只要话术合规，是稳定增长品类 |
| **建议** | 话术严格限制在「呵护血脂健康」范围内，禁止提及「血管」「心脑血管」 |

### 🟡 谨慎区（有空间但风险提升）

#### 4. 益生菌（肠道健康方向）— ⚠️ 核心品类，话术纪律是生命线

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 H（益畅/镜脂）、客户 M（小蓝瓶/体重益生菌）、客户 Wk（400 亿活菌） |
| **新公约影响** | 🟡 中高风险 |
| **理由** | 益生菌本身属于「普通膳食」可正常直播，但话术极易滑向「调节肠道菌群」→「治疗便秘」→「治疗作用」。新公约重申「普通商品禁宣疗效」且加了「跨类目医疗宣传禁止」条款 |
| **关键区分** | ✅ 可说：「唤醒肠道新活力」「蹲坑腿麻选手」「肚肚好舒服」 ❌ 不可说：「治疗便秘」「调节肠道菌群」 |
| **机会** | 益生菌是膳食行业最大的品类之一，已有完整的「可用话术白名单」。新公约对没有白名单的品牌是打击，对有白名单的品牌是**竞争壁垒** |
| **风险** | 客户 M 的「体重益生菌」涉及「减肥」方向，新公约明确将「减肥」列为需资质的内容，**体重管理相关话术需全面收紧** |
| **建议** | ① 客户 H/M/Wk 三家分别建立话术合规卡 ② 客户 M 体重益生菌话术需从「减肥」切换到「曲线管理」「甩掉负担」等放宽话术 ③ 客户 Wk 的「400 亿活菌」不要强调菌群数量的医学意义 |

#### 5. 叶黄素 / 护眼品类 — ⚠️ 话术空间窄

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 N（叶黄素是 ADQ 测试方向）、潜在新客户 |
| **新公约影响** | 🟡 中等风险 |
| **理由** | 放宽话术仅限「呵护双眼」「眼疲劳」「用眼过度的近视人士」，但新公约将「缓解视疲劳」等功效宣称纳入更严格审查。「护眼」本身不算医疗宣传，但「改善视力」「预防近视」绝对踩线 |
| **机会** | 叶黄素是当前窗口期的 ADQ 重点测试方向，政策收紧反而淘汰白牌竞争者 |
| **建议** | 话术严格限制在「呵护双眼」「护眼」范围，不提「视力」「近视」「恢复」 |

#### 6. 传统滋补 / 药食同源 — ⚠️ 中医功效话术有放宽但红线清晰

| 维度 | 判断 |
|------|------|
| **涉及客户** | 潜在品类拓展方向（枸杞、燕窝、花胶等） |
| **新公约影响** | 🟡 需特别注意 |
| **理由** | 新公约明确**无资质账号不得涉及「专业中医」内容**（气血辨证、舌象、穴位等），**不得宣传「特定饮食具有治病/养生功效」**。但内部规则已对「祛湿」「护肝」「养胃」等常见中医功效做了放宽（如「祛湿清体，活力满满」可用） |
| **机会** | 药食同源类目有明确的放宽白名单，合规品牌可以在白名单范围内安全操作 |
| **风险** | 新公约的「伪养生禁止」条款 + 「功效宣称禁止」条款，对没有严格执行白名单的直播间是**高压红线** |
| **建议** | 此类目如果拓展，必须逐品逐句审核话术，不能靠主播自由发挥 |

### 🔴 高风险区（需高度警惕或策略调整）

#### 7. 体重管理 / 代餐 / 减肥方向 — 🚨 新公约直接命中

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 M（体重益生菌）、客户 D（辟谷粉/代餐） |
| **新公约影响** | 🔴 高风险 |
| **新增风险点** | ① 「减肥」被列为需健康科普资质的内容 ② 「夸大宣传」红线明确列出「减肥」 ③ 「伪养生禁止」——极端减肥方式被明确列入违规 |
| **可用话术** | 仅限放宽范围：「助力曲线管理」「甩掉油腻」「美食任性吃」「21 天控卡计划」「好身材计划」（注意：这些是**广告侧**放宽话术，直播侧执行可能更严） |
| **核心矛盾** | 客户 D 的明星大场（多位 S 级达人）走量模式天然需要「减肥效果」卖点，但新公约把「减肥」从灰色地带推入了红线区 |
| **建议** | ① 客户 D 话术**必须**从「减肥」全面切换到「轻体」「曲线管理」「好身材计划」 ② 客户 M 体重益生菌的代言学者新品发布会（5 月）话术需提前审核，避免出现「减肥」相关表述 ③ 明星直播间需提前给明星团队发放话术红线卡，**明星口播出错的合规成本极高** |

#### 8. 儿童营养品 / 儿童增高 — 🚨 新公约设置准入门槛

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 Y（GABA 儿童增高方向）、客户 Wk（儿童脑营养方向） |
| **新公约影响** | 🔴 高风险 |
| **新增风险点** | ① 「生长发育」内容需健康科普资质——无资质账号严禁涉及「儿童青少年生长发育建议或推广相关课程」 ② 「夸大宣传」列出「增高」——宣传产品具有增高功效是所有主播禁止的行为 |
| **对客户 Y 的影响** | 客户 Y 的核心卖点涉及「儿童增高」，新公约把「增高」和「生长发育」都纳入高压管控。**「增高」在直播间已不可触碰**。结合外部不确定性，当前「冻结+观望」策略完全正确 |
| **对客户 Wk 的影响** | 客户 Wk 计划切入「儿童脑营养」，涉及儿童生长发育范畴。新公约要求此类内容需健康科普资质，如果在直播间讲「儿童大脑发育」「促进智力」等内容，**直接触发准入红线** |
| **建议** | ① 客户 Y 维持冻结策略不变 ② 客户 Wk 暗棋搭建阶段，话术**绝对不能提「儿童生长发育」「增高」「智力发育」**，只能走「营养补充」的安全话术 ③ 客户 Wk 正式起量前需评估是否申请「健康科普」资质 |

#### 9. CEO IP / 科普型带货模式 — 🚨 模式本身受到根本性挑战

| 维度 | 判断 |
|------|------|
| **涉及客户** | 客户 H（CEO IP）、客户 Y（达人 IP） |
| **新公约影响** | 🔴 模式风险 |
| **核心冲突** | 新公约建立了一个根本性的二分法：① 「医疗健康科普直播」= 需要资质 + **不能带货** ② 「普通电商带货直播」= 可以带货 + **不能出现医疗养生内容** |
| **对客户 H CEO IP 的影响** | 该 IP 的直播模式是「科学科普 + 产品带货」，这恰好是新公约试图切割的两件事。如果被认定为「医疗健康科普」→不能挂车；如果走「普通带货」→不能讲科学原理、不能做成分科普 |
| **灰色地带** | 该 IP 讲的是「科学知识」而非「医疗诊疗」，但新公约对「医疗健康科普」的定义很宽——「涉及人体健康、养生保健等医学知识的分享与解读」都算。**讲益生菌对肠道的作用机理，是否属于「人体健康的医学知识解读」？** 这个定义边界非常模糊 |
| **建议** | ① **客户 H 周年庆（CEO IP 出席）前必须与治理侧确认**：科普内容是否会被归类为「医疗健康科普」 ② 做好预案 A（科普和带货分段进行，科普时不挂车，带货时不讲科学原理）和预案 B（申请健康科普资质但放弃直播间带货功能） ③ 与治理同事见面时，**可以把该 IP 作为「边界案例」来询问**，探出平台对「科研人设+带货」模式的态度 |

## 四、新公约带来的结构性机会

### 机会 1：合规品牌的「护城河效应」加深

> 新公约提高了直播合规门槛 → 白牌/小品牌被清洗 → **合规品牌的竞争环境改善**

- 客户 N、H、M 这种有完整合规团队 + 话术白名单的品牌，在新政下反而是受益者
- 没有白名单的品牌会频繁踩线被限流/下架，流量会自然向合规品牌倾斜
- **建议**：与客户同步新公约内容时，将「合规 = 竞争壁垒」作为核心叙事，增强客户投入信心

### 机会 2：「普通膳食营养补充食品」赛道打开

> 保健食品（蓝帽子）直播受限 → 但「普通膳食营养补充食品」不受限

- 4 月 4 日微信小店新增类目后，「普通膳食」赛道已有明确的政策绿灯
- 客户 N 主力品类（维矿物质/钙铁锌/蛋白粉）恰好在这个赛道内
- **建议**：帮客户梳理产品线，将更多品可能从「保健食品」类目切换到「普通膳食」类目（前提是产品本身符合普通食品标准）

### 机会 3：行业话术白名单可以变成「共建」资源

> 新公约要求合规，但没给具体的行业话术指引 → **谁先建白名单谁就有话语权**

- 我们已有完整的 27 项保健功效禁用/可用话术对照表
- 已有中医功效放宽话术表
- **建议**：与治理侧主动提出共建「膳食行业话术白名单」，将资源优势转化为合作关系

### 机会 4：全域通 + ADQ 双链路作为「安全通道」的价值提升

> 直播间合规风险提升 → 广告侧（ADQ/全域通）的放宽话术对标更清晰 → 投放链路反而更安全

- ADQ 和全域通的素材审核有明确的放宽标准，而直播间的合规更依赖主播口播，不确定性更高
- **建议**：对高风险品类（体重管理/儿童营养），引导客户加大 ADQ/全域通投放比例，减少对直播间口播的依赖

## 六、会议后修正（2026.4.21 实际结论）

> ⚡ 以下修正基于当天与直播治理侧的实际沟通结果，覆盖了会前分析中的部分误判。

### 修正 1：管控体系是「两条线」而非「一条线」

**会前假设**：直播治理侧管所有直播间合规问题
**实际情况**：直播治理侧只管**内容**（话术、画面、行为是否触碰医疗健康底线），**商品合规**（蓝帽子资质、类目归属、功效承诺、流量帽）由电商侧管控

| 问题 | 应找谁 |
|------|--------|
| 直播间话术涉及疾病 | 直播治理侧 |
| 保健食品流量帽口径 | **电商侧** |
| 蓝帽子类目上架规则 | **电商侧** |
| 商品功效承诺审核 | **电商侧** |
| 违规弹窗/录屏 | 需先判断来源方 |

### 修正 2：CEO IP 科普带货模式风险下调

| 会前判断 | 修正后判断 | 理由 |
|---------|-----------|------|
| 🔴 模式风险——科普 + 带货二分法受根本性挑战 | → **🟡 中风险，需分清管控方** | 直播治理侧管「内容是否涉医」，不管「能不能挂车」。CEO 如果做科学知识分享（非疾病诊疗/非医学知识），在直播治理侧看来不一定触发红线。**但仍需与电商侧确认带货环节的合规** |

**具体指引**：
- CEO 讲「益生菌是什么、肠道里有多少种菌」= 🟢 科学科普，不涉及疾病
- CEO 讲「益生菌能改善便秘/治疗肠炎」= 🔴 涉及疾病，绝对违规
- CEO 讲「肠道蠕动的原理」= 🟡 灰色地带，**取决于语境**——如果紧接着说「所以用我们的产品」则违规

### 修正 3：话术合规逻辑从「词汇」升级为「语境」

**会前认知**：建立「禁用词/可用词」白名单就能解决问题
**实际情况**：治理侧明确——**同一个词在不同语境下判断可能完全不同**

| 词汇 | 语境 A（可能 OK） | 语境 B（违规） |
|------|---------------|-------------|
| 「肠道蠕动」 | 纯科普讲解人体生理 | 暗示产品能促进肠道蠕动解决便秘 |
| 「营养补充」 | 描述产品属性 | 暗示能补充到治疗疾病的效果 |
| 「免疫力」 | 一般性提及人体免疫系统 | 宣称产品能增强免疫力 |

**影响**：之前规划的「膳食行业话术合规白名单」需要升级——不能只列词汇，必须附带场景/语境说明。

### 修正 4：广告侧放宽话术 ≠ 直播侧也能用

**会前假设**：广告侧（ADQ）的放宽话术在直播间也适用
**实际情况**：直播治理侧和电商（广告审核）侧是**独立体系**，各自的放宽标准**不通用**

**影响**：之前的「可用话术白名单」（来自素材规范）是广告侧标准。在直播间使用这些话术，需要**单独验证直播治理侧是否认可**。
