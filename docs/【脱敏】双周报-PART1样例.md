## 二、汇总行 — 整体描述

**核心事项：**
整体日均消耗双周环比 +47.8%，为节后复工集中放量期。但增长主要由头部驱动 —— 活跃客户数反降 14.1%（-36 家），中小客户回暖滞后。

结构性变化需关注：

1. **爆品下滑需挽救**：客户 K1 日耗骤降 -71.7%，客户 K2 -41.9%（且 ROI 破 1），客户 K3/K4/K5 消耗归零或接近归零 —— 这几家需紧急排查原因并做挽回动作
2. **新品冒出需跟进**：B1 从低基数爆发至 +746%，ROI 健康，是本双周最亮眼的新增量，需要趁势加码绑定
3. **多主体客户Z稳健增长**：五主体合计 +22.9%，ROI 健康，38 节前夕核心品类窗口期，需重点锁定预算
4. **节点窗口**：新锐益生菌品牌W本期零消耗，距节点仅剩 1 周，必须立即确认预算启动节奏
5. 大盘 ROI 改善至 1.84（+6.7%），CPM -20.3%，但 CTR -17.3%、CTCVR -22.5%，素材效率亟需迭代

**所需支持：**

1. 审核部：S 级客户 N / H 审核卡点集中解决（头部商家通过率影响起量效率）
2. 风控部：W 即将回归投放，需提前对接素材合规预审
3. 运营部：客户 N 某主体 ROI 仅 1.38，需运营侧出具深度诊断报告；38 节行业素材模板支持
4. 销售老板：中小客户活跃度降 14%，建议推出 38 节专项激活政策 / 流量扶持方案
5. 品牌部：客户 H 十周年品牌项目对接，腾讯新闻方案跟进

**下双周 TODO：**

行业策略：

1. **头部做稳**：资源向 N/H/Z 倾斜，确保 38 节前夕消耗稳中有升
2. **新客加码**：B1 (+746%) 势头强劲，重点陪跑帮助其从 B 级向 A 级跃升
3. **挽回下滑**：K1/K2/K3 逐一排查原因制定挽回方案
4. **激活沉睡**：W 零消耗客户激活，锁定节点预算
5. **多主体 Z 节点冲刺**：推动预算加码冲击日耗 +60%

## 三、客户 N（S级 · 基础维矿 · TOP1）

**核心事项：**
三主体日均合计占大盘 25.1%，加权 ROI 1.97（+12.7%）。主体 A 表现最强（ROI 健康），主体 B 自营小店渠道 ROI 全主体最高，但主体 C（代理）ROI 仅 1.38 为核心痛点。本双周完成年度复盘 + ADQ 投放复盘，年度规划基本锚定。

结构细看：

- 主体 A 直播 +35.3% + 小店 +49.4%，双渠道均放量，健康
- 主体 B 自营小店 ROI 达 2.65，是全主体最高效率渠道
- 主体 C（代理）走 CID 链路，ROI 1.37 远低于主体 A 的 2.00，说明代理素材/人群策略有明显优化空间

**所需支持：**

1. 运营侧：出具主体 C 的 ROI 深度诊断（对比主体 A 的素材/人群/出价策略差异）
2. 推进视频号直播 + 搜一搜品专新渠道拓展
3. 推进小店直购基建 —— 主体 B 自营小店 ROI 2.63 证明该链路大有可为

**下双周 TODO：**

1. 陪跑复盘运营操作，重点解决主体 C 的 ROI 从 1.38 → 目标 ≥1.8
2. 推客沟通，推进视频号直播 + 搜一搜品专新渠道拓展
3. 推进小店直购基建扩量

## 九、方法论沉淀：双周报为什么这样写？

这份 PART1 解决了**销售向上汇报最痛的 4 个问题**：

1. **结构标准化**：销售/客户/数据/事项/支持/TODO 六列直接对应 Excel，老板拿走就能合并到全行业大表
2. **数据先行 + 结论先行**：所有客户先有"环比 + ROI"两个数字，再有"核心事项"叙述，避免老板还要找数字
3. **明确卡点**：每个客户都有"所需支持"段落，把跨部门需求清单化，老板可以直接转发
4. **可追溯**："下双周 TODO" 是下期对账的基础，没落地的下次必须解释

> 💡 军师在每两周末替我完成 80% 的初稿，我只需要在最后一小时做"判断 + 删改"，从写 3 小时到改 30 分钟。
