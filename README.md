## 本地预览

```bash
# 直接用浏览器打开
open index.html

# 或起一个本地静态服务（可选）
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 把 `townhall-site/` 内的所有文件 push 到一个公开仓库的根目录
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)`
3. 等 1-2 分钟，访问 `https://<username>.github.io/<repo-name>/`
